# Github Codespaces

## Objectives
- Create first repository
- Lauch codespaces IDE
- close / reopen codespace
- Install python extension

## Terms
- *Computer Language* - `A language that a person can write instructions that the computer will understand how to do. Languages have to be converted to 1s and 0s (compiled) so the computer can understand it. Some languges are not truly compiled and instead have another program that interprets the language. These are called scripting laguages`
- *IDE / Integrated Development Enviorment* - `A computer program that has at least a text editor but often has additional tools to assist a developer when writing computer code`
- *Python* - `A powerful/popular computer language that can be used in various applications, but has a simple way of writting (syntax) and is a great language to start with`

## Create first repository
- Log into github
- Click on the green "new" button in the top left
- On the form:
    - repositry name : tm-2024-classes
    - Description : In Class Lessons and projects
    - Make it private
    - Check "Add a README file"

## Launch codespaces
- Click Hamburger menu (3 horizontal lines) in the top left 
- - Click Codespaces
- click the green "New Codespace" button
- On the form:
    - Select repository: Choose "tm-2024-classes"
    - Make sure you select only "2 core" for machine type
    - Click create Codespace

## Create a file
- Click the hamburger menu in the top left
    - Select File -> new text file
    - Add Text to the editor something like "I have created a file"
    - Click (in the hamberger menu) file -> save as and git it a name like "newtext.txt"
> /workspaces/tm-2024-classes/newext.txt
    - Click the green "ok"

# Close and re-open
- Close the tab
- Go to https://github.com/codespaces
- Look at the bottom for for the codespace you just left
> it will have a strange name like "crispy space potato"
- Click on the name and you should see the file you just made.

# Install Python extensions
- Click on the 4 boxes with one seeming to jump off the box 
- Type in python in the search bar
- The top one should be "Python Language support extension" (made by microsoft)
- Click the green install buton next to it
